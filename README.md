# Research Mentor AI — React UI

A polished frontend prototype for the Research Mentor AI minor project.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Included screens

- Dashboard
- Explore
- Research gaps
- Novelty check
- Experiment plan
- Risk & timeline
- Paper writer
- Mentors
- My projects

## Notes

This is a frontend prototype with mock data. Replace the mock data/actions with your FastAPI endpoints, PostgreSQL/Chroma/FAISS services, and LangGraph agent workflow when the backend is ready.
